# comp523-teamf
Project Website for COMP523 Team F

Static HTML/CSS site, deployable on Vercel with zero config (no build step).

## Local preview

```bash
npx serve .
```

## Deploy

Push to GitHub and import the repo in Vercel, or run `vercel` from this directory.

## Structure

- `index.html` — Project intro
- `team.html` — Team roles, contact info, client info
- `schedule.html` — Recurring meeting schedule
- `rules.html` — Team rules
- `journal.html` — Meeting journal (reverse chronological)
- `links.html` — Related links
- `deliverables.html` — Deliverables repository

Content marked `TODO` throughout is a placeholder for the team to fill in.
